> Version: **1.0**
>
> Status: Draft

---

# Overview

Stud.xo follows a **relational database design** using **PostgreSQL**. The database is designed around a **Workspace-first architecture**, where every resource belongs to a workspace, and every workspace belongs to a user.

This approach keeps data organized, scalable, and easy to extend in future versions.

---

# Design Principles

- Every user can own multiple workspaces.
- Every workspace contains its own chats, documents, notes, memories, and tags.
- Resources are isolated between workspaces.
- Authentication is separated from application data.
- Soft deletion will be supported where appropriate.
- UUIDs will be used as primary keys.
- All timestamps are stored in UTC.

# Core Entities

## 1. User

Stores account information and authentication details.

### Relationships

- One User → Many Workspaces

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
| id | UUID | Primary Key |
| full_name | String | NOT NULL |
| email | String | UNIQUE |
| password_hash | String | NOT NULL |
| avatar_url | String | Nullable |
| theme | Enum | Default: Light |
| created_at | Timestamp | NOT NULL |
| updated_at | Timestamp | NOT NULL |

---

## 2. Workspace

A workspace groups all learning resources together.

Examples:

- Machine Learning
- DSA Preparation
- Web Development

### Relationships

- Belongs to one User
- Has many Chats
- Has many Documents
- Has many Notes
- Has many Memories
- Has many Tags

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
| id | UUID | Primary Key |
| user_id | UUID | Foreign Key |
| name | String | NOT NULL |
| description | Text | Nullable |
| icon | String | Nullable |
| color | String | Nullable |
| created_at | Timestamp | NOT NULL |
| updated_at | Timestamp | NOT NULL |

---

## 3. Chat

Represents a conversation.

### Relationships

- Belongs to one Workspace
- Has many Messages

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
| id | UUID | Primary Key |
| workspace_id | UUID | Foreign Key |
| title | String | NOT NULL |
| model | String | Nullable |
| created_at | Timestamp | NOT NULL |
| updated_at | Timestamp | NOT NULL |

---

## 4. Message

Stores individual user and AI messages.

### Relationships

- Belongs to one Chat

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
| id | UUID | Primary Key |
| chat_id | UUID | Foreign Key |
| role | Enum | User / Assistant / System |
| content | Text | NOT NULL |
| tokens | Integer | Nullable |
| created_at | Timestamp | NOT NULL |

---

## 5. Document

Stores uploaded learning materials.

Supported formats:

- PDF
- Markdown
- TXT

Future support:

- DOCX
- PPTX
- Images

### Relationships

- Belongs to one Workspace

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
| id | UUID | Primary Key |
| workspace_id | UUID | Foreign Key |
| title | String | NOT NULL |
| file_name | String | NOT NULL |
| file_type | String | NOT NULL |
| file_size | Integer | NOT NULL |
| storage_path | String | NOT NULL |
| uploaded_at | Timestamp | NOT NULL |

---

## 6. Note

Stores notes created by users or generated by AI.

### Relationships

- Belongs to one Workspace

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
| id | UUID | Primary Key |
| workspace_id | UUID | Foreign Key |
| title | String | NOT NULL |
| content | Text | NOT NULL |
| source | Enum | User / AI |
| created_at | Timestamp | NOT NULL |
| updated_at | Timestamp | NOT NULL |

---

## 7. Memory

Stores long-term information remembered by the AI.

Examples:

- Preferred language
- Learning goals
- Current project

### Relationships

- Belongs to one Workspace

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
| id | UUID | Primary Key |
| workspace_id | UUID | Foreign Key |
| key | String | NOT NULL |
| value | Text | NOT NULL |
| created_at | Timestamp | NOT NULL |
| updated_at | Timestamp | NOT NULL |

---

## 8. Tag

Used to organize resources inside a workspace.

Examples:

- React
- AI
- Semester 5
- Interview

### Relationships

- Belongs to one Workspace

### Fields

| Field | Type | Constraints |
|---------|------|-------------|
